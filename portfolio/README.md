# Shaun Dias — Portfolio (Clean V3)

A cleaned-up, less cramped version of the portfolio with a structured editorial hero, orange/black visual language, responsive navigation, project filters, project detail modals, scroll reveals and the existing Formspree contact flow.

## Files
- `index.html` — site markup
- `styles.css` — all styling and responsive breakpoints
- `script.js` — interactions and project data
- `assets/profile.jpg` — single portrait used across the site
- `assets/Shaun_Dias_CV_UK.docx` — downloadable CV

## GitHub Pages
Keep the same structure inside your repository's `portfolio/` folder and push the files. No build step is required.
